# Jomeca Center — staff dashboard design

Standalone React/TypeScript staff UI preview. All displayed guests, tickets, money and configuration are synthetic examples. The API adapter never sends requests. Mutations are disabled. There are no staff passwords, customer records, API services, database files, secrets or payment accounts. This is not an authenticated staff portal and must never be used to record real payments.

Run npm ci and npm run build. Vercel supports the included SPA configuration. GitHub Pages builds use GITHUB_PAGES=true to set the repository base path.
